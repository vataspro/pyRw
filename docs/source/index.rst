pyRw documentation
==================

**pyRw** is a lightweight **Python** package implementing 
multiple histogram reweighting as introduced in 
:cite:`Ferrenberg:1988yz` and :cite:`Ferrenberg:1989ui`.

For a paedagogical approach to the implementation of the 
algorithm the relevant section of :cite:`Newman1998-tj`
may be of interest.

See :ref:`quick-start-section`.

.. note::
   While most numerical features are complete, 
   this project is still under development.
